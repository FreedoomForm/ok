The endpoint fetches assigned-customer orders through the period window (from/to params first, then the courier's own dated orders, then the current day), merges them with the stored-courier rows, and filters every dated order through the effective assignment alongside the existing client/courier disabled-day resolution. A named browser regression walks the whole contract: a period assigning courier B shows the legacy courier-A order in B's portal and hides it from A, and disabling the period restores the stored assignment for A while B loses it.
