## Порядок циклов (исторический)

## §1 Universal Buttons (как в приложении)
- Набор: plus (плюс), edit (изменить), sms (сообщения), scanner (сканер), delete (удалить), search (искать) + новые: key (ключ), enable (включить), disable (выключить).
- Расположение: шапка сверху каждой страницы, как в приложении.
- Кнопки навигации по страницам: в приложении снизу → на сайте справа (сохраняем компактность + удобство большого экрана).

## §2 Язык и тема
- Одна кнопка-цикл: нажатие RU→UZ (перевод сайта), ещё нажатие UZ→RU. English удалён полностью.
- Кнопка переключения темы остаётся.

## §3 Правая боковая панель
- Chat, Settings, Database переводятся в правую боковую панель как отдельные страницы.

## §4 Корзина = режим через кнопку «Ключ»
- Страница «Корзина» убирается из навигации.
- Обычный режим: нажатие ключа → фон зелёный. Теперь нажатие «Корзина» → режим корзины; выбранные в обычном режиме элементы НЕ сбрасываются.
- В режиме корзины ключ красный; выбранные в корзине элементы тоже не сбрасываются.
- Повтор: ключ (красный→зелёный) → нажатие корзины → возврат в обычный режим; все выборы сохранены.
- В режиме корзины «+» восстанавливает выбранные элементы в обычный режим.
- SMS + ключ: ключ зелёный + фон SMS зелёный = авто-отправка включена; нажатие SMS → фон красный + системное сообщение в чат «авто-отправка отключена». После этого ключ остаётся активным (зелёный) до повторного нажатия.
- Enable/Disable: две новые кнопки; работают с ключом и без; имеют режимы вкл/выкл + обычные.

## §5 Календарь и контракты
- Перенос календаря с кнопками включить/выключить и оплачен/не оплачен.
- Вместо выбора скутера → выбор курьера при создании/изменении клиента.
- Окно клиента: дни (напр. пн, вт) → курьер-ответственный → оплачен/нет → период контракта в календаре.
- Первый день контракта = включённый день, горит жёлтым весь период в назначенные дни; курьер получает уведомления в чат сайта; заказы контракта видны.
- Отключение дня админом → последующие дни контракта неактивны: без уведомлений и без заказов в списке курьера.
- В день окончания контракта появляется подсветка завершения.

## §6 Чат (унифицированный, «как остальные, но немного иначе»)
- Слой контактов слева от левого сайдбара; по умолчанию контакт «Система».
- После создания аккаунта администратору приходит приветствие.
- Ввод внизу, отправка; сообщение появляется внизу шапки профиля (universal buttons выше), переход в подробности.
- Сообщения системы справа; от контактов слева с цветом контакта (как Telegram).
- «Создать контакт»: имя, номер, цвет из невыбранных, профессиональная иконка; если пользователя с номером нет — система сообщает.
- Все окна: Сохранить (правый нижний угол), Назад (левый нижний угол).
- Контакты: редактировать / удалить / включить / выключить.
- Отключённый контакт не может писать; удалённый → корзина (может писать, восстанавливается в режиме корзины).
- Три режима контактов: удалённые / включённые / отключённые.
- Режим истории действий и временные ветки учитывают контакты.
- Авто-отправка сообщений идёт через внутренний мессенджер.

## §7 Вход клиентов
- Вход клиента через логин администраторов.
- При создании клиента: логин = номер телефона, пароль по умолчанию = номер телефона.

## §8 Унификация клиентского и курьерского сайтов
- После админ-сайта переделать клиентский и курьерский сайты в унифицированный стиль.
- Перенести все universal buttons и недостающие страницы.
- Разница только: набор страниц, персонализированная информация, специальные страницы (унифицируются тоже).

## §9 Страница «Машруты» (16-я страница)
- Левый сайдбар: курьеры (имя, цвет, профессиональная иконка), справа от основного сайдбара страниц.
- Шапка: universal buttons; справа «Продолжить» (следующий день/задача), слева «Предыдущий»; в центре — выбранный день и период.
- Карта: заказы = квадраты с первыми буквами имени и фамилии клиента.
- Правый сайдбар: линии маршрутов курьера: кубики заказов по местам + отдельный кубик курьера с именем маршрута; фон линии = цвет маршрута.
- Раскрытие маршрута → список заказов; перемещение с 1-го на 9-е место и т.д.
- «+» → маршрут с именем и цветом → выбрать курьера → на карте рисуется полупрозрачный четырёхугольник цвета курьера → заказы внутри связываются в один маршрут (по местам в правом сайдбаре) → маршрут рисуется по дорогам Ташкента.
- Перемещение заказа (9→4) → перерисовка маршрута.
- Сохранить (правый нижний) / Назад (левый нижний).
- По умолчанию при входе: период с сегодня до следующего понедельника включительно.
- Маршруты: редактировать / удалить / включить / выключить через universal buttons.
- Выключенный маршрут не применяется к будущим неделям; включённый — применяется автоматически; новый заказ в четырёхугольнике включённого маршрута попадает в него.
- Каждую неделю создаётся НОВЫЙ маршрут (не продлевается старый); маршрут связан с контрактом.

## §10 Время заказа
- Убрать ввод времени при создании/удалении заказа.

## §11 Готовка
- «+» → страница выбора блюд для дня (список названий).
- Справа от названия блюда: (+) (поле «сколько») (−).
- Раскрытие блюда → ингредиенты с учётом сета/группы заказа.
- Справа от ингредиента: (+) (число) (−) — израсходовано (г/л, единица указана); автоподсчёт с возможностью правки.
- Линия квадратов цветов над Сохранить/Назад — выбрать цвет записи готовки.
- Сохранить (правый нижний) → запись готовки в левом сайдбаре; Назад (левый нижний).
- Universal edit/delete — для записей готовки в левом сайдбаре.

## §12 Критерии приёмки
- Каждая страница: одинаковая шапка universal buttons.
- RU/UZ полное покрытие, EN отсутствует.
- Все окна: Сохранить справа-снизу, Назад слева-снизу.
- Build + tests зелёные; каждый цикл commit+push.
